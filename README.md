# Hospital ER Data Warehouse & Business Intelligence Project

## Project Overview

This project was developed as part of the Data Warehousing and Business Intelligence module.

The objective was to design and implement a complete Hospital Emergency Room Data Warehouse solution and build Business Intelligence reports for analytical decision-making.

## Technologies Used

* SQL Server
* SSIS (SQL Server Integration Services)
* SSAS (SQL Server Analysis Services)
* Power BI
* DAX
* Data Warehousing
* ETL
* OLAP
* Star Schema

## Assignment 1 – Data Warehouse Development

Key Activities:

* Data source analysis
* Hospital ER data warehouse design
* Star schema implementation
* Fact and dimension table creation
* SCD Type 2 implementation
* ETL workflow development

## Assignment 2 – Business Intelligence Development

Key Activities:

* SSAS Cube implementation
* OLAP operations
* Roll-up and Drill-down analysis
* Slice and Dice operations
* Pivot analysis
* Power BI dashboard development
* DAX measure creation
* Interactive business reporting
